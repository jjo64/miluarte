# Miluarte - Portafolio Creativo

Este es el portafolio web personal de **Miluarte**, un estudio creativo multidisciplinar enfocado en ilustración, diseño gráfico, concept art y diseño de espacios en 3D.

El proyecto es una aplicación de página única (SPA) de alto rendimiento construida con tecnologías modernas y enfocada en una estética editorial de primera calidad.

## 🛠️ Stack Tecnológico

- **Core**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Empaquetador**: [Vite 6](https://vite.dev/)
- **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animaciones**: [Framer Motion (motion/react)](https://motion.dev/) & [GSAP](https://gsap.com/)
- **Enrutamiento**: [React Router v7](https://reactrouter.com/)

## 🚀 Desarrollo Local

Para levantar el proyecto en tu entorno local, sigue estos pasos:

1. **Instalar dependencias**:
   ```bash
   pnpm install
   # o usando npm:
   # npm install
   ```

2. **Iniciar el servidor de desarrollo**:
   ```bash
   pnpm run dev
   # o usando npm:
   # npm run dev
   ```

3. **Construir para producción**:
   ```bash
   pnpm run build
   # o usando npm:
   # npm run build
   ```

## 📂 Estructura del Proyecto

- `src/app/pages`: Páginas principales de la aplicación (Home, Colección, Layout base, 404).
- `src/app/components`: Componentes reutilizables como la cabecera, la galería horizontal y las secciones de servicios.
- `src/assets`: Ilustraciones y recursos visuales en alta definición.
- `src/styles`: Archivos CSS globales y configuración de variables de tema de Tailwind v4.
